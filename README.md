# Malvan Tadka — Kalyan

A mobile-first restaurant website concept for Malvan Tadka, Kalyan.

## Included
- Responsive landing page with coastal editorial styling
- Menu category filters
- Enquiry list with quantity controls
- WhatsApp enquiry handoff (not an online payment or confirmed order)
- Zomato and Swiggy/Dineout links
- Address, phone, directions and table enquiry links

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Important
This is an independent website concept, not an official restaurant website. It is pending approval from the restaurant owner. Menu items are illustrative categories; confirm actual dishes, prices, hours, photos, contact details and ordering arrangements with the restaurant before public launch.

The photography uses remote Unsplash image URLs. Replace with approved restaurant photography before launch.
